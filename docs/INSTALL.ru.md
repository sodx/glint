# Установка Glint на Mac

Glint показывает, что сделали ваши программы: значения, логи, SQL, исключения, время выполнения и
вызовы LLM из PHP, Python, Node, браузера и WordPress, в окне на вашем Mac. Ваш агент для кода
(Claude Code, Cursor и другие) видит те же события. Все данные остаются на вашем компьютере.

## Что нужно

- Mac с Apple silicon (M1 и новее) и macOS 11 и новее. На Mac с Intel эта сборка не запустится.
- Для `glint()` в коде: PHP 8.0+, Python 3.9+ или Node 18+, то, чем вы пользуетесь. Glint берёт те
  версии, которые находит ваш терминал (Homebrew, nvm, pyenv и так далее).

## Установка

1. Откройте `Glint-<версия>-macos-arm64.dmg` и перетащите Glint в «Программы».

2. Откройте Glint из «Программ». В первый раз macOS покажет сообщение, что не может проверить
   приложение: эта сборка не подписана и не нотаризована через Apple. Нажмите «Готово». Затем
   откройте «Системные настройки», раздел «Конфиденциальность и безопасность», прокрутите вниз до
   сообщения «Glint заблокирован для защиты Mac», нажмите «Всё равно открыть» и подтвердите
   паролем. Это нужно сделать один раз.

   То же самое через Терминал:

   ```bash
   xattr -dr com.apple.quarantine /Applications/Glint.app
   ```

   Если macOS пишет, что приложение «повреждено и не может быть открыто», это тот же карантин
   скачанного файла, и команда выше его снимает.

3. В строке меню появится маленькая искра, откроется окно Glint. Разрешите уведомления, когда
   macOS спросит: через них Glint сообщает, что программа упала или ждёт вашего ответа.

4. Нажмите на искру правой кнопкой и выберите **Set up this Mac…**. Через несколько секунд придёт
   уведомление со списком того, что настроено. После этого откройте новое окно терминала, чтобы
   оболочка подхватила изменения.

   То же самое из Терминала:

   ```bash
   /Applications/Glint.app/Contents/Resources/bin/glint install
   ```

## Проверка

```bash
glint doctor
```

`glint doctor` покажет, запущен ли Glint, работает ли `glint()` в PHP, Python и Node и какие
агенты знают о Glint. Затем отправьте что-нибудь:

```bash
echo '<?php glint(["hello" => "from PHP"]);' > /tmp/hi.php && php /tmp/hi.php
python3 -c 'glint({"hello": "from Python"})'
node -e 'glint({ hello: "from Node" })'
```

Каждое значение появится в окне Glint. Там клавиша `?` открывает полную документацию с примером
каждого метода на каждом языке, а `,` открывает настройки.

## Что установка меняет на Mac

Установка записывает эти файлы, а `glint uninstall` убирает их обратно:

- `~/Library/LaunchAgents/local.glint.glintd.plist`, чтобы служба Glint запускалась при входе;
- `~/.glint/` со службой, утилитой командной строки, SDK, настройками и базой событий;
- `99-glint.ini` в папке конфигурации PHP, чтобы в каждом PHP-скрипте был `glint()`;
- `glint.pth` в пользовательских site-packages Python, чтобы `glint()` был в каждой программе на
  Python;
- несколько помеченных строк в профиле оболочки (`~/.zshrc` для zsh), чтобы `glint()` был в Node,
  а команда `glint` была в PATH;
- запись MCP-сервера для найденных агентов (Claude Code, Cursor, VS Code, Windsurf, Gemini CLI,
  Codex) и хуки Claude Code в `~/.claude/settings.json`. Перед первым изменением каждого файла
  сохраняется копия `.glint-backup`.

Glint ничего не отправляет за пределы вашего Mac. SDK молчат, когда `APP_ENV` или `NODE_ENV`
равны `production`, поэтому продакшен с тем же кодом не затронут.

## Удаление

```bash
glint uninstall
```

Затем закройте Glint через его меню, переместите приложение в Корзину и удалите `~/.glint`, если
хотите убрать и сохранённые события с настройками.

## Если что-то не так

| Что видно | Что делать |
|---|---|
| macOS не открывает приложение | Шаг 2: «Конфиденциальность и безопасность», «Всё равно открыть», или команда `xattr`. |
| Нет искры в строке меню | На MacBook с вырезом значки могут прятаться за ним. Закройте приложение с длинным меню или смотрите на значок Glint в Dock: на нём появляется метка при ошибках. |
| Нет уведомлений | «Системные настройки» > «Уведомления» > Glint, разрешите. |
| `glint()` не определён | Откройте новое окно терминала. Запустите `glint doctor`, он скажет, чего не хватает. Код через `php -r` его не получает, PHP-файл получает. |
| `glint: command not found` | Откройте новое окно терминала или запустите `/Applications/Glint.app/Contents/Resources/bin/glint`. |
| Установка сообщила о проблеме | Посмотрите `~/.glint/setup.log`. Папке конфигурации PHP на некоторых системах нужен `sudo`; запустите команду установки из шага 4 в Терминале, чтобы увидеть подробности. |
